# Part 1 — 本地大模型与智能体应用

状态：**规划中**

## 目标

1. 在本机部署本地大模型（已通过 Ollama 完成）
2. 让本地模型充当 model provider，以 API 形式接入自己写的应用
3. 应用形态由易到难推进：CLI → Web

## 方案

- **模型服务**：Ollama，对外提供 OpenAI 兼容接口 `http://127.0.0.1:11434/v1`，因此应用侧可以直接复用 `openai` SDK，无需自研协议。
- **主模型**：`qwen3:8b`（量化后约 5GB，可完整放进 8GB 显存，响应速度可接受）。
- 本机另有一个 36B 的 MoE 模型，显存放不下、需要大量 CPU 卸载，只作为"本地能跑大模型"的能力展示，不作为应用主模型。

## 计划

- [ ] CLI 对话程序（先跑通端到端链路）
- [ ] Web 服务（后端 + 简单前端页面）
- [ ] 接入 YOLO 的推理结果，形成完整应用
